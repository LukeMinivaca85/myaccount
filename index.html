O que acontece ao permitir?

O serviço solicitante recebe um retorno simples dizendo que a permissão foi concedida. A página adiciona parâmetros na URL de retorno para o serviço reconhecer que o usuário autorizou a continuação.

1. O serviço abre a Lukintosh Account Exemplo: Developer manda o usuário para esta página de permissão com app e redirect.
2. A pessoa permite ou cancela O usuário escolhe se quer continuar para o serviço.
3. A página retorna para o destino permitido O retorno acontece somente para domínios da allowlist.
4. O serviço recebe o resultado A URL volta com lukintosh_sso=success ou lukintosh_sso=denied.
